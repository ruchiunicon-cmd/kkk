# NSE Options & Indices Dashboard (free)

## Chalane ka tareeka (Windows / Mac / Linux)
1. Python 3.10+ install karo (python.org).
2. Is folder mein terminal kholo:
   pip install -r requirements.txt
   streamlit run app.py
3. Browser mein http://localhost:8501 khulega.
4. Phone par dekhna ho: PC aur phone ek hi WiFi par ho, phone mein terminal mein dikhne wala "Network URL" kholo.

## Free online hosting (optional)
- Streamlit Community Cloud (free) par GitHub se deploy ho sakta hai.
- Lekin NSE kayi baar cloud IPs ko block karta hai. Tab Option Chain tab mein NSE se
  download ki hui CSV upload karo, ya app apne PC par chalao.

## Data sources
NSE option chain, FII/DII, participant OI (nseindia.com), Yahoo Finance (yfinance).
NSE ke endpoints unofficial hain; kabhi bhi badal sakte hain.
